# 猪猪影视 · PIG-TV

一款影视聚合客户端，基于开源项目 TVBox 的内核改造，界面全部重做。
电视版、手机版两个壳，共用同一套片源配置。

> 纯客户端，**不含任何片源**。接口需自行配置，支持 TVBox 的 config JSON / XML 格式。

---

## 特点

- **全站聚合搜索** —— 一次搜索覆盖全部可用站点，同一部片在几个站搜到就分别列出，可只看某个站
- **分类浏览 / 榜单** —— 电影、电视剧、综艺、动漫、纪录片等分类，支持二级筛选
- **片头广告自动跳过** —— 识别播放列表里的贴片广告段并剔除
- **网盘播放** —— 支持夸克、UC、阿里云盘、天翼、123 等网盘登录后播放 4K 资源
- **直播** —— 内置一组公开直播源，也可自己加
- **收藏 / 观看历史 / 继续观看**
- **深浅色主题**，手机版另有跟随系统的自动模式

## 下载

到 [Releases](../../releases) 页下载，四个包按设备选一个：

| 文件 | 适用 |
|---|---|
| 电视版-64位 | 近几年的大屏盒子、智能电视（首选） |
| 电视版-32位 | 老盒子、老电视 |
| 手机平板-通用版 | 手机 / 平板（不确定就选这个，兼容性最好） |
| 手机版 | 手机（arm64，包体更小） |

系统要求：Android 5.0 及以上。

## 安装说明

- 电视版需要用遥控器操作，装好后按「确定」进详情、左右切分类。
- 首次使用请先在「设置 → 片源接口」里配置接口地址；内置了一个公开源，可直接用。
- 从旧版本升级可直接覆盖安装；如果提示签名冲突，先卸载旧版再装。
